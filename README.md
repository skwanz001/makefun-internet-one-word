One word for the whole internet: **groupchat**. Eight billion people in one group chat with no admin — someone always typing, someone always leaving, someone always replying at 3am. `main.py` writes that single word to `/output/entry.txt`, nothing else.

## Run it

```sh
python3 main.py
```
